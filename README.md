# Проект "Резервное копирование"

Программа для резервного копирования фотографий с профиля (аватарок) пользователя vk в облачное хранилище Яндекс Диск

Основные этапы:
- Получаем фотографии с профиля
- Сохраняем фотографии максимального разрешения на Я.Диске
- Для имени фотографий используем количество лайков
- Сохраняем информацию по фотографиям в json-файл
